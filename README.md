A clean, beginner-friendly Java CLI application designed to calculate total student marks, average percentage, and standard academic letter grades based on user-entered subject scores.

---

## 🌟 Key Features

- **📊 Dynamic Subject Marks Entry**: Accepts marks obtained out of 100 across arbitrary numbers of courses.
- **🧮 Automatic Percentage Computation**: Aggregates total marks and calculates exact decimal percentages.
- **🏷️ Academic Letter Grade Allocation**:
  - $90\% - 100\% \rightarrow$ **Grade A+**
  - $80\% - 89\% \rightarrow$ **Grade A**
  - $70\% - 79\% \rightarrow$ **Grade B**
  - $60\% - 69\% \rightarrow$ **Grade C**
  - Below $60\% \rightarrow$ **Grade D / Fail**
- **🎥 Video Walkthrough**: Includes `Task_2.mp4` demonstrating execution.
